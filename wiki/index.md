# ExternalApiPlugin — вики проекта

Клиентский плагин для **ЛОЦМАН:PLM** (АСКОН). По нажатию пункта меню на панели ЛОЦМАН Клиента плагин берёт id текущего выделенного в дереве объекта и открывает диалог выбора типа отчёта. Поддерживает 8 типов отчётов (спецификации, групповые спецификации, ведомости — с и без ПЗ). При выборе отчёта отправляет `POST` с id на внешний сервис (`/specifications/{versionId}` для единственного реализованного типа). Адрес и маршрут сервера — в `server-config.json` рядом с `.dll`, не в коде. Для остальных типов показывает заглушку "в разработке".

Проект появился как исследование SDK ЛОЦМАН:PLM на примере готового модуля маркировки (`raw/Модуль маркировки`) и клиентского SDK (`raw/Client`), и постепенно вырос в рабочий минимальный плагин.

## Ключевые каталоги репозитория

- `raw/Client/` — клиентский SDK ЛОЦМАН (справка `LoodsmanClientApi.chm`, примеры плагинов на C#/Delphi/VC, интерфейсы Frames/Services/Common). Использовался только как справочный материал, в сборку не входит.
- `raw/Модуль маркировки/` — реальный сторонний плагин (штрихкодовая маркировка), разобран как эталон легаси-контракта `.pgi`.
- `ExternalApiPlugin/` — исходники нашего плагина.
- `tools/test_server.py` — локальный HTTP-сервер для тестирования без интернета.
- `.vscode/` — конфигурация сборки в VS Code.
