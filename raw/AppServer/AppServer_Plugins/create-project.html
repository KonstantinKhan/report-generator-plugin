Создание и подготовка проекта в Microsoft Visual Studio

Запустите Microsoft Visual Studio и создайте новый проект типа "Библиотека классов"

Присвойте проекту имя, на свое усмотрение (но лучше - осмысленное, отражающее суть приложения)

В дополнительных сведениях, в качестве платформы укажите версию .NET, используемую сервером приложений в вашей версии ЛОЦМАН:PLM (версию .NET можно посмотреть в документации к ЛОЦМАН:PLM, например в документе "Установка Комплекса Решений АСКОН").
В нашем примере будет использоваться .NET 8.
